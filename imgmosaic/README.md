# imgmosaic

## 题面（可直接粘贴）

马赛克（非均匀块网格 + 面积加权）。约束：整数块内取均值与块内和/面积一致（≤1e-12）；非整数块按面积加权平均，与解析积分对照（≤1e-12）；整除时两条路径结果一致（≤1e-12）；必须支持列宽/行高数组构成的非均匀块网格，且块面积总和与图像面积差 ≤1e-12；块网格必须与逐像素积分对照（≤1e-12）；块大小 1 时恒等；100 万像素不超过 700 ms；非法块尺寸与非均匀网格长度不符可区分报错。 工作目录为仓库内的 imgmosaic/。 验收：cd imgmosaic && python -m pytest tests -q。 实现只允许使用 Python 标准库。

## 运行方式

```bash
cd imgmosaic && python -m pytest tests -q
```

初始 15 failed（实现前）。仅使用 Python 标准库。
